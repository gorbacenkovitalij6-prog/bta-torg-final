# 📹 Как загрузить видео для главного экрана

## Шаги для загрузки видео:

1. **Скачайте видео с Google Drive**
   - Откройте ссылку: https://drive.google.com/file/d/1EasJUzLk-qjS8wvZmiFiZbAAByJgipBk/view?usp=sharing
   - Нажмите кнопку "Скачать" (Download)
   - Сохраните файл на компьютер

2. **Загрузите в проект Same**
   - В интерфейсе Same нажмите на кнопку "Upload Files" в левой панели
   - Выберите путь: `brabus-clone/public/videos/`
   - Перетащите или выберите скачанное видео
   - **ВАЖНО:** Переименуйте файл в `hero-bg.mp4`

3. **Проверьте результат**
   - Откройте главную страницу
   - Видео должно автоматически проигрываться на фоне Hero секции
   - Если видео не отображается, попробуйте обновить страницу (F5)

## 🎬 Характеристики видео:

- **Формат:** MP4
- **Путь:** `/videos/hero-bg.mp4`
- **Режим:** Autoplay, Loop, Muted
- **Позиция:** Fullscreen cover (растягивается на весь экран)
- **Overlay:** Темный полупрозрачный слой для контраста

## 🔧 Технические детали:

Видео будет:
- Автоматически воспроизводиться при загрузке страницы
- Зацикливаться бесконечно
- Без звука (для лучшего UX)
- Адаптивно масштабироваться под любой размер экрана
- Работать на всех устройствах включая мобильные

## ⚠️ Важно:

- Файл должен называться **точно** `hero-bg.mp4`
- Путь должен быть **точно** `brabus-clone/public/videos/hero-bg.mp4`
- Рекомендуемый размер видео: до 10-20 МБ для быстрой загрузки
- Рекомендуемое разрешение: 1920x1080 или выше

## 🎨 Альтернатива:

Если видео слишком большое или не загружается:
- Можете сжать видео с помощью онлайн-инструментов (например, HandBrake, CloudConvert)
- Уменьшите разрешение до 1280x720 для меньшего размера файла
- Используйте кодек H.264 для лучшей совместимости
