## 🐛 Известные проблемы

### Runtime Errors
1. ⚠️ **IMG failed to load** - некоторые Rutube thumbnails
   - Причина: CORS policy
   - Решение: Использовать fallback изображения

2. ⚠️ **Cross origin request** - Next.js warning
   - Причина: Preview iframe в Same
   - Решение: Добавить `allowedDevOrigins` в next.config.js (опционально)

### База данных
3. ⚠️ **SQL миграция не выполнена**
   - Файл: `.same/FINAL-MIGRATION.sql`
   - Требуется: Добавить поля views, transmission, engine, fuel_type, color
   - Требуется: Создать таблицу daily_views
   - Требуется: Создать функции increment_car_views, get_daily_stats
