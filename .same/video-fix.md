# 🎥 Исправление проблемы с видео на Hero секции

**Дата:** 11 февраля 2026
**Версия:** v288
**Статус:** ✅ Исправлено

---

## 🐛 Проблема

**Симптом:** YouTube видео не отображается на Hero секции главной страницы.

**Причины:**

1. **YouTube блокирует автовоспроизведение в iframe**
   - Многие браузеры блокируют автовоспроизведение видео с внешних источников
   - YouTube может не разрешать встраивание в iframe на некоторых доменах

2. **CORS и Content Security Policy**
   - Браузеры могут блокировать внешний контент из соображений безопасности
   - YouTube требует специальные заголовки для встраивания

3. **Проблемы с параметрами iframe**
   - Не все параметры YouTube API работают корректно
   - `transform: scale(1.5)` может вызывать проблемы с рендерингом

4. **Зависимость от внешнего сервиса**
   - Если YouTube недоступен, видео не загрузится
   - Медленное интернет-соединение замедляет загрузку

---

## ✅ Решение

### Использовано локальное видео вместо YouTube iframe

**Было:**
```tsx
<iframe
  className="absolute inset-0 w-full h-full pointer-events-none"
  style={{
    width: '100vw',
    height: '100vh',
    objectFit: 'cover',
    transform: 'scale(1.5)',
  }}
  src="https://www.youtube.com/embed/L9_Qdsd67X0?autoplay=1&mute=1&loop=1&playlist=L9_Qdsd67X0&controls=0&showinfo=0&rel=0&modestbranding=1&playsinline=1"
  title="Hero Background Video"
  allow="autoplay; encrypted-media"
  allowFullScreen={false}
/>
```

**Стало:**
```tsx
<video
  className="absolute inset-0 w-full h-full object-cover"
  autoPlay
  muted
  loop
  playsInline
  preload="auto"
>
  <source src="/videos/hero-bg.mp4" type="video/mp4" />
  Your browser does not support the video tag.
</video>
```

**Кодек:** H.264 (рекомендуется)

### Оптимизация (опционально):

Если видео слишком большое для production:

1. **Сжатие с HandBrake:**
   - Разрешение: 1920x1080 или 1280x720
   - Битрейт: 2-4 Mbps
   - Кодек: H.264
   - Качество: RF 20-23

2. **Онлайн сервисы:**
   - CloudConvert: https://cloudconvert.com/
   - Clideo: https://clideo.com/compress-video

3. **Команда FFmpeg:**
   ```bash
   ffmpeg -i hero-bg.mp4 -vcodec libx264 -crf 23 -preset medium -vf scale=1920:1080 -acodec aac -b:a 128k hero-bg-compressed.mp4
   ```

## 🔧 Параметры HTML5 video

### Использованные атрибуты:

- **`autoPlay`** - автоматическое воспроизведение при загрузке
- **`muted`** - без звука (обязательно для autoplay в большинстве браузеров)
- **`loop`** - зацикливание видео
- **`playsInline`** - воспроизведение внутри страницы на iOS (не fullscreen)
- **`preload="auto"`** - загружать видео заранее
- **`object-cover`** - масштабирование с сохранением пропорций

### Альтернативные параметры:

```tsx
// Если нужно контролировать загрузку
preload="metadata" // загружает только метаданные
preload="none"     // не загружает до play()

// Если нужен постер (превью)
poster="/images/video-poster.jpg"

// Если нужен контроль
controls  // показывает кнопки управления
```

## 🔍 Отладка

### Если видео не воспроизводится:

1. **Проверьте путь к файлу:**
   ```bash
   ls -lh public/videos/hero-bg.mp4
   ```

2. **Проверьте консоль браузера:**
   - Откройте DevTools (F12)
   - Перейдите во вкладку Console
   - Ищите ошибки загрузки видео

3. **Проверьте формат видео:**
   - MP4 с H.264 кодеком - лучшая совместимость
   - WebM - современная альтернатива
   - Избегайте AVI, MOV, WMV

4. **Проверьте размер файла:**
   ```bash
   # Если больше 200 MB - сожмите
   ffmpeg -i hero-bg.mp4 -vcodec libx264 -crf 23 hero-bg-compressed.mp4
   ```

### Fallback для старых браузеров:

```tsx
<video ...>
  <source src="/videos/hero-bg.mp4" type="video/mp4" />
  <source src="/videos/hero-bg.webm" type="video/webm" />
  {/* Fallback изображение если video не поддерживается */}
  <img src="/images/hero-fallback.jpg" alt="Hero background" />
</video>
```
